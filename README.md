# منصة تحليل نتائج المدرسة

منصة عربية متكاملة لاستيراد نتائج المدرسة، ربط المعلمين بموادهم وصفوفهم، تحليل الاختبارات الأربعة، حساب القيمة المضافة، وطباعة تقارير A4 قابلة للتخصيص.

## المزايا الرئيسية

- لوحة تحكم تنفيذية وتحليل المدرسة والصفوف والمعلمين والأقسام.
- اختلاف الدرجة الكلية لكل اختبار مع المقارنة العادلة بالنسب المئوية.
- حساب القيمة المضافة للطالب والمعلم والصف والقسم والمدرسة.
- مستويات أداء وحد نجاح قابلة للتعديل مع تحقق من التداخل والفجوات.
- استيراد قاعدة المعلمين ثم ربط ملفات النتائج التي لا تحتوي اسم المعلم.
- توحيد الشعب إلى الصيغة `7/1` و`8/2` وما شابه.
- اختيار منسق المادة تلقائيًا من قاعدة المعلمين وإظهاره في توقيع التقرير.
- مركز تقارير لكل اختبار أو مقارنة بين اختبارين، لكل صف أو معلم.
- منشئ تقارير مخصصة لاختيار الحقول والعنوان والترويسة والتذييل والاتجاه.
- تحكم في نصوص التقارير والشعار والختم والتوقيعات وبيانات البرمجة والتصميم.
- حفظ صريح للإعدادات، وتراجع عن التعديلات غير المحفوظة، ونسخ JSON احتياطية.
- تقارير مضبوطة للطباعة في صفحة A4 واحدة متى كان محتوى التقرير من النوع الملخص.

## البدء

```bash
pnpm install --frozen-lockfile
pnpm dev
```

## النشر

راجع [DEPLOYMENT.md](./DEPLOYMENT.md) لخطوات GitHub وVercel وطريقة الحفظ في كل بيئة.

## ملفات Excel النموذجية

توجد داخل `public/` نماذج جاهزة لقاعدة المعلمين ونتيجة المادة والاستيراد الشامل. يتضمن نموذج المعلمين عمود **اسم منسق المادة**، ويستخدمه النظام تلقائيًا حسب مادة التقرير.
